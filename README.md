# Enterprise-Asset-Management-SAP-S4HANA
Durchgängige Simulation eines Instandhaltungsprozesses in SAP S/4HANA (Enterprise Asset Management) – von der Störmeldung über Planung und Ressourcensteuerung bis hin zu Kostenanalyse, technischem und kaufmännischem Abschluss. Demonstriert integriertes Prozessverständnis über Instandhaltung, Materialwirtschaft und Controlling hinweg.
